Experiment Details

Experiment Name

Webcam Brightness and Processing-Time Measurement

Objective

To record frame-level brightness values and processing time using a webcam, visualize the measurements, and analyze the variation observed during the experiment.

Environment

- Programming language: Python
- Computer vision library: OpenCV
- Camera: Built-in webcam
- Operating system: macOS
- Experiment type: Local webcam measurement

Recorded Variables

- Timestamp
- Frame brightness
- Frame processing time

Data Collection

Measurements were recorded continuously during a webcam session and stored in a CSV file for subsequent analysis.

Analysis

The collected data was used to calculate:

- Number of observations
- Average brightness
- Minimum brightness
- Maximum brightness
- Average processing time

Graphs were generated to visualize brightness variation and frame processing time.

Reproducibility

The experiment can be repeated using the same measurement scripts. Different camera conditions, hardware configurations and capture sessions may produce different results.

Limitations

This experiment represents a preliminary measurement session. Further controlled trials are required before drawing broader conclusions.
